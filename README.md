## About

A hands-on learning project focused on exploring the ServiceNow platform through the Tour Travel Request application.

This project was created to become familiar with the ServiceNow environment, understand its interface, explore its development tools, and learn the fundamentals of building applications within the platform.

## Learning Progress

Started with the ServiceNow fundamentals and platform navigation, following the official Quick Guides and hands-on exercises to understand how the platform works.

The focus was on learning the environment and getting familiar with its tools rather than building a fully functional enterprise application.

## What I Learned

- Understanding the ServiceNow platform and its purpose.
- Navigating the interface and exploring the application navigator.
- Understanding tables, fields, records, forms, and lists.
- Exploring App Engine Studio and application development tools.
- Creating and configuring basic application components.
- Understanding how records are stored and managed within the platform.
- Exploring application access controls and basic permissions.
- Working with travel request records and mandatory fields.
- Becoming familiar with the ServiceNow development environment.
